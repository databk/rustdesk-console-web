# 网页远控使用说明

进入“网页远控”后，左侧输入设备 ID，或从右侧列表选择设备。连接需要被控设备密码，或等待对方同意。

## 设备选择与远程画面

未连接时直接显示设备选择，不用先滚过一块空白画面。左侧输入 ID 不会筛掉右侧设备；“仅在线”开关和刷新按钮放在设备列表标题旁。

开始连接后进入远程画面。工具栏默认收起，点击右上角“工具”展开：

- **悬浮显示**：默认方式。工具栏覆盖在画面右侧，不改变画面大小。
- **停靠右侧**：工具栏占据右侧区域，画面在剩余空间内等比缩放；收起恢复全部空间。
- **窄屏**：使用悬浮工具栏，避免远程画面被挤得过窄。
- **全屏**：画面占满可用区域，底部不再保留工具和提示条。工具、退出全屏和断开始终可以操作。

侧栏按剪贴板、文件传输、输入辅助、声音分组。内容在栏内滚动，全屏和断开按钮固定在栏内底部。方向键可切换工具；焦点在工具栏内时按 Escape 收起，焦点回到入口。在远程画面内按 Escape 仍交给远端。

## 直接粘贴，不必打开面板

在本机复制文字或截图，点击远程画面中要粘贴的位置，然后按 Ctrl+V；Mac 本机使用 Cmd+V。网页在这次粘贴操作中读取内容，发送到远端剪贴板并触发远端粘贴。截图通常由浏览器提供为 PNG；目前支持文字和符合限制的 PNG，不支持任意文件或富文本格式。

这条路径依赖浏览器触发的粘贴事件，不要求后台持续读取系统剪贴板。剪贴板面板保留为浏览器受限、图片另存和复制远端内容时的备用入口。仅点击面板“发送到远端剪贴板”时仍是同步内容，不自动触发粘贴。

发送前会检查键盘/剪贴板权限和当前画面；切屏、断开、离开画面或窗口，以及新的点击/按键会取消尚未发出的粘贴快捷键。图片沿用 4 MiB 编码大小、4096 边长和约 419 万像素限制。

界面显示“已向远端发送粘贴操作”表示已发送，不能代替目标应用的结果。原生协议没有系统剪贴板写入完成确认；当前会等待本地发送队列清空并留出短暂兼容间隔，远端繁忙或图片较大时仍可能需要重试。不要在粘贴尚在发送时切换远端输入位置。

## 直接选择设备

“可访问设备”来自当前登录账号的设备权限范围，显示名称、ID、操作系统和在线状态。可筛选仅在线设备、翻页或刷新；点击设备卡片会填入并连接对应 ID。管理员按后端规则可能看到更大的设备范围。

出现在列表中不表示可以免密控制，仍需被控设备密码或对方同意。列表为空或暂时加载失败不影响手动填写 ID 连接。

## 四组工具

| 工具 | 操作 |
| --- | --- |
| 剪贴板（备用） | 发送文本到远端剪贴板，或作为文本输入；复制远端文本；发送、选择、预览和保存 PNG 图片。 |
| 文件传输 | 单独连接并认证文件会话，输入远端目录，打开文件夹，选择上传文件或点击文件下载；处理进度、取消和同名文件。 |
| 输入辅助 | 切换定位、滚动或移动放大画面的模式，重置缩放，使用修饰键、快捷按键和软键盘文本输入。 |
| 声音 | 手动开启远端声音，调节音量或静音；断开远控后自动停止。 |

收起或切换面板不会中断文件传输，文件传输进行中时工具按钮旁会显示提示点。收起输入辅助时会释放页面按下的修饰键，避免远端保持按下状态。系统或浏览器保留的快捷键仍可能无法发送到远端。

## 提示与兼容性

界面跟随 Console 的明暗主题；面板切换使用短时动画，并尊重系统的“减少动态效果”设置。远程画布不添加坐标缩放过渡。

文件会话仍需独立认证，工具分组不会改变原生权限或连接协议。旧协议、撤权和文件错误以简短提示保持可见，点击展开详情；展开侧栏时提示随工具栏显示，避免被遮住。操作错误会自动展开详情，点击外部可收起。图片仍仅支持受限大小的 PNG；缺少文件写入流的浏览器仍采用有限大小下载回退。

本次布局的移动验证使用浏览器窄屏模拟；实际手机上的编解码、系统剪贴板、手势和软键盘仍需真机验收。

## 升级范围

只需更新前端验收镜像，后端 Web Client 配置、RustDesk 服务、证书和数据目录沿用既有设置。发布锁文件下的构建、TypeScript、全部前端回归和生产静态资源检查由验收工作流执行。镜像固定标签以本次交付记录为准。
