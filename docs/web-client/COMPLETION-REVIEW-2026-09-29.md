## 独立审查与修复

此前代理消息传递失败后，改由只读的独立 CLI 执行实际审查。首轮覆盖本任务负责的后端配置模块，以及前端协议、传输、媒体、输入、界面、集成、打包和来源追溯，发现一项 P1 和三项 P2 问题。随后针对这些修复及新增的登录跳转修改进行独立复核，没有发现剩余可操作问题。这属于代码审查，不是正式安全认证。

| 发现的问题 | 修复后的行为 | 回归证据 |
| --- | --- | --- |
| 替换令牌后，身份刷新等待期间仍保留旧账号 | 刷新前同步清除身份，立即使账号所属配置和旧页面资源不可用 | 身份刷新保持等待状态的真实 AuthSync／模型集成测试、页面清理测试、独立的 Umi／模型／页面链路内存探针 |
| 立即终止 Worker 可能丢弃排队中的输入释放事件 | 立即分离旧页面，允许排队释放与会话清理执行；收到匹配的关闭确认后终止，并保留一秒超时兜底 | 异步排队 Worker、旧 ACK、迟到帧释放、超时／错误测试，以及真实 Worker 命令处理器测试 |
| 组合鼠标按钮变化遗漏释放 | 根据指针事件 buttons 同步三个支持的按钮；丢失指针捕获时释放鼠标持有状态，不释放独立按住的键盘修饰键 | 输入回归测试、覆盖全部 36 种按下／释放排列的独立内存探针 |
| ACK 失败关闭解码器后仍发布当前帧 | ACK 后再次检查是否已清理；已清理时关闭当前帧，不继续发布；页面也拒绝会话失败后的帧 | 解码器重入清理测试，以及相同 generation 下页面失败后拒绝帧的测试 |
| 登录丢失 Web Client 深链 | 匿名／认证过期流程保留内部 Web Client 目标，普通登录用户也能返回 | 跳转、重复认证失败、外部／相似路径及 401 处理器测试 |

关闭交接只延后资源清理完成的时点；等待期间，旧画面、密码、本地文本、远端文本和账号配置不会继续对页面可用。输入释放仍是尽力交付：原生端拒绝输入、网络故障或整个浏览器退出，都可能阻止送达。该机制不是全局远控会话撤销能力。
