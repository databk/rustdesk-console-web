# 五项扩展：操作、边界与待验收清单

日期：2026-09-30，Asia/Shanghai。E1–E5 已完成代码实现、独立审查问题修复、生产构建和本机 Windows/Chrome 开发验收。20 个套件、144 条回归通过。真实手机、未覆盖的环境组合及维护者试用仍单独列出，详见[本批验收报告](EXTENSIONS-ACCEPTANCE-2026-09-30.md)。首版历史报告不能替代本批证据。

## 操作

按原有流程登录 Console，通过配置的 WSS 中继连接 Windows 被控端。保留原生密码/本机批准、签名验证及 KX 0 风险提示；验证失败不降级。
1. **多显示器（E4）**：选择“显示器”。切换前释放可释放的输入；新显示信息和新解码帧到达前禁用坐标输入。显示原点可以为负数；原生 PeerInfo 更新处理显示器增减。一次只订阅一屏。
2. **声音（E1）**：点击“播放远端声音”创建并启动 Web Audio。浏览器需通过 Opus 解码配置检测，原生需允许 Audio；可调音量、静音或停止。格式切换清空缓存，撤权、断线、账户更换和页面进入后台停止声音；返回前台后显式重新开启。不含麦克风/通话。
3. **图片（E3）**：点击“发送剪贴板 PNG”，或选择 PNG 文件；收到远端 PNG/RGBA 后可复制 PNG 或下载。系统剪贴板读写都由明确操作触发。浏览器拒绝剪贴板访问时，使用选择文件/下载路径。PNG 之外的 SVG、HTML 和动画不支持；含压缩 ICC/文本元数据的 PNG 会拒绝，请重新导出为普通 PNG，避免元数据解压造成额外分配。
4. **文件（E2）**：点击“连接文件会话”，独立输入密码或在被控端批准。该会话复用握手代码，但有自己的套接字、认证和代次；桌面登录不是文件授权，未启用 enable_file_transfer 文件剪贴板。打开远端目录；“/”表示 Windows 驱动器列表。选择一个或多个本地文件逐个上传，点击远端普通文件下载。重名时默认等待决定，可保留或显式覆盖；原生判定相同元数据时显示已跳过。只支持 Windows 盘符绝对路径，不支持 UNC、设备路径、递归目录和符号链接操作。
5. **触控（E5）**：轻点定位并左键点击，移动开始拖动，长按触发右键。双指仅缩放本地画面，不生成远端拖动；“远端滚动”模式发送滚轮，“移动放大画面”模式平移。可重置缩放。在全屏容器内打开软键盘，完成输入法组合后显式发送 Unicode 文本；Control/Alt/Shift 和 Tab/Return/Escape/Backspace 按钮提供修饰键与常用控制键。

撤销键鼠权限后仍可能存在原生按下状态；本实现不绕过撤权发送释放。恢复授权时由既有 RemoteSession 先释放此前成功发送的状态，再启用 UI。详见 INPUT-RECOVERY-2026-09-30.md。

## 资源与失败边界

| 路径 | 边界 |
| --- | --- |
| 音频 | 每个原生 AudioFrame 为原始 Opus 包；TOC 计算微秒时长，按包累计，无伪造固定帧率。最多 16 个解码排队、4 个待主线程消费 PCM、300ms 播放队列；落后时丢弃积压，不追赶播放陈旧声音。音频失败单独提示。 |
| 图片 | 编码最多 4 MiB、边长最多 4096、最多 4,194,304 像素。RGBA 长度精确匹配；zstd 检查声明大小、窗口和输出。PNG 在浏览器解码前检查头与块边界，解码后重新编码；同时仅一次转换，并在异步完成后复查权限和代次。浏览器解码器内部内存不属于 JS 可保证范围。 |
| 上传 | 最多排队 32 个 File 引用，一次一个原生 job；按 128 KiB slice 读取，WebSocket 发送缓冲超过 1 MiB 时等待。发送末块不算完成：等待原生 Done，再读取目标目录核对文件名与长度。 |
| 下载 | 每块最多 128 KiB；Worker 等待主线程写入确认再消费下一块。优先用户选择的写入流；缺少流式保存 API 时最多 16 MiB Blob 回退。流式完成需协议 Done、长度一致和写入流 close 成功；Blob 回退只能证明已交给浏览器下载，后续保存结果由浏览器决定。 |
| 文件生命周期 | 错误、权限撤销、取消、连接/账户代次变化会取消任务、清空队列并 abort 写入句柄。原生错误只映射通用提示，不输出原始错误/凭据日志。无响应 30 秒按失败处理；不承诺断点续传或内容哈希校验。 |
| 多屏 | 会话 generation 之外使用 displayGeneration 隔离帧、绘制确认和输入。旧屏包被丢弃并确认，新解码器等待关键帧。显示器数量、几何和像素尺寸沿用原有防御性上限。 |
| 触控 | 最多两个触点；缩放范围 1–3 倍，显式滚轮/平移模式。取消、失焦、旋转和隐藏释放权限允许的拖动并停止长按计时。 |

原始消息和传输队列仍受既有 8 MiB 单包、16 MiB/64 包队列限制。浏览器磁盘太慢造成入站超限会安全终止文件会话；不无限缓存文件，也不增加额外服务或依赖。
